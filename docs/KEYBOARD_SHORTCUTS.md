# Junexis Studio — skróty klawiaturowe

Najpewniejszym źródłem aktualnych skrótów jest **Command Palette**
(`Ctrl+Shift+P`), która pokazuje aktywne przypisanie obok każdej komendy.

## Nawigacja

| Skrót | Działanie |
|---|---|
| `Ctrl+P` | Quick Open pliku |
| `Ctrl+Shift+P` | Command Palette |
| `Ctrl+Shift+E` | Explorer |
| `Ctrl+Shift+F` | Search |
| `Ctrl+Shift+M` | Problems |
| `Ctrl+Shift+G` | Source Control |
| `Ctrl+Shift+D` | Run and Debug |

## Plik i edycja

| Skrót | Działanie |
|---|---|
| `Ctrl+S` | zapisz aktywny dokument |
| `Ctrl+W` / `Ctrl+F4` | zamknij aktywną kartę |
| `Ctrl+Z` | cofnij |
| `Ctrl+Y` / `Ctrl+Shift+Z` | ponów |
| `Ctrl+X`, `Ctrl+C`, `Ctrl+V` | wytnij, kopiuj, wklej |
| `Ctrl+A` | zaznacz wszystko |
| `Ctrl+L` | zaznacz linię |
| `Ctrl+G` | przejdź do linii |
| `Ctrl+F` | wyszukiwanie w dokumencie |
| `Ctrl+H` | zamiana w dokumencie |
| `F3` / `Shift+F3` | następne / poprzednie trafienie |

## Kod i diagnostyka

| Skrót | Działanie |
|---|---|
| `F2` | rename symbol |
| `Ctrl+.` | Code Actions / Quick Fix |
| `F12` | przejdź do definicji |
| `Shift+F12` | znajdź referencje |
| `F8` / `Shift+F8` | następny / poprzedni problem |

## Build, Run i Debug

| Skrót | Działanie |
|---|---|
| `F5` | Run |
| `F6` | Build |
| `F7` | Debug |
| `Shift+F5` | Stop |
| `F9` | przełącz breakpoint |
| `Ctrl+F10` | Run to Cursor |
| `F10` | Step Over |
| `F11` | Step Into |
| `Shift+F11` | Step Out |

Skróty są kontekstowe: operacja wymaga otwartego workspace, obsługiwanego
aktywnego pliku i dostępnego polecenia profilu. Jeśli skrót nie wykonuje
akcji, sprawdź status na pasku Run & Debug oraz Toolchain Doctor.
