## Dla projektantów i kontrybutorów

Pozostała dokumentacja jest podzielona na 4 kategorie:

- `rozdzialy/` – rozdziały przewodnika (architektura i kontrakty)
- `plany/` – uporządkowane plany etapów i milestones
- `pomysly/` – notatki koncepcyjne / kanwa
- `implementacje/` – notatki z rozpoczęcia implementacji i minimalne interfejsy
